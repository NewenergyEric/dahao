# 搭好 · dahao

把 AI 搭好，让你用得起来。

搭好面向不太会 AI 的使用者，以及帮他们准备电脑的人。爱人、家人、朋友和自己都是常见使用对象。以一件想完成的小事开始，把部署准备、工具选择、工作规则、Skills、验收和后续维护连起来。

Skill 名称是 `dahao`，调用入口 `$dahao`。用户动作仍是配置、检查、更新；底层命令仍为 configure / check / update。品牌更名不迁移客户实例、配置键或已有清单进度。

## 视觉与动作

- 粉色、奶油色和深梅色，手绘墨线与有材质的生成图像。保留亲近感，避免礼品广告与写实桌面静物主导。
- 大标题使用得意黑字体的专用子集 Dahao Display，正文使用 Dahao Text；具体原字体和许可见 THIRD_PARTY_NOTICES.md。标题短、字号有对比、留出倾斜与运动空间。
- 连续素材移动、镜头尺度变化、文字有节奏地入场、选择与标注产生明确变化。不能仅换背景，再把六页文字淡入当成影片。
- 真实清单、规则文件和目标任务帮助解释步骤；不要把每一段都装进同样的白色卡片。素材不能用 SVG、PPT 或伪截图代替。
- 保持中文为主、英文独立排版。先看代表帧，再看完整播放；编码合格不等于视觉已获认可。

## 承诺与证据

完整的 AI 部署与持续使用是产品目标。当前提供七步准备清单、选择项、行为模板和 Windows 项目内合成示例。真实依赖、Agent 安装和规则/Skill 加载仍待接入；影片不得把选择动作或合成示意包装成安装成功。

用户本次确认名称为搭好，要求恢复动感与个性字体，并避免 PPT 式产出。视觉改版已按此制作，最终喜好仍以用户反馈为准。

# Agent Gift · 上市与产品化底稿

采用作者的 skill-launch-studio / launch-workbook、copy-and-page，以及 skill-productization / workbook 和证据契约。

- 用户：给爱人、客户或自己准备助手电脑的非技术用户；由另一个 Agent 带着完成。
- 问题：不知道电脑缺什么、要装什么、如何判断真的可用，希望先做成一件日常小事。
- 岗位：依据用户用途、目标系统和访问条件，给出逐步准备计划，执行已支持且获授权的动作，交出安装/加载/任务分层验收与接续记录。
- 保留成果：Client Setup 的固定包、身份、覆盖、漂移、幂等和恢复基础；不复制客户数据、私有日志或蓝色营销材料。
- 关键修正：FDE 工程工具与亲民礼物产品分开，避免一次改色覆盖两个不同用户的叙事。
- 输入：自然语言需求；脚本仅接收 Windows/Mac、本地/另一台、访问是否已有、运行器选择及任务是否已确定，不接收秘密值。
- 确定性工具：只读分流、hash/身份/路径检查、计划、包写入、恢复、合成任务、发布白名单。Agent 负责理解用途、解释缺口和适配方案；真实电脑安装尚无执行适配。
- 已验证承诺：Windows 隔离示例的配置/更新/恢复；系统与访问分流不会触发安装或连接。
- 目标承诺：从空电脑到可工作的 Agent；明确为计划，不当作已完成。
- 中文优先，英文辅助；粉色 #F2BBCB、奶油色 #FFF8F3、莓果色 #71334E。独立于 Client Setup 蓝色 FDE 版。
- 发布：本地预览及 Library 关键帧；未授权创建本项目的公开仓库，未选择项目许可证。

本轮交付中文首页与 1280×720 静态关键帧。本地字体覆盖 212 个非空字符、缺字 0；运行时字体加载检查通过，渲染后实际查看布局和文字，无遮挡。没有新全片，因此时长、编码、循环与英文影片检查不适用。待用户确认方向后再决定是否做影片。

人类入口 README.md；Agent 入口 .agents/skills/agent-gift/SKILL.md；配置/检查/更新沿现有三入口。product-evidence.json 明确区分 verified 与 planned，工具审核只证明引用/哈希及声明一致，不能代替真实部署。

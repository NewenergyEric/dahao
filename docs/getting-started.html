  1. 本机 Agent 带着做

    先让本机 Agent 找候选电脑，你确认目标，再建立连接。

    连接 checklist · Windows / Mac

    已经在目标电脑上：Agent 核对电脑、账户、系统和项目目录，无需开启 SSH。

    • 本机 Agent 检查自己的 SSH 客户端，读取已有局域网设备记录，列出候选；你只需确认目标。
    • 找不到或认不出时，按下面对应系统的方式取得必要连接信息；地址用来选目标，安全校验码用来防止连错电脑。不要发送密码或完整网络配置。
    • Agent 校验四段数字均在 0–255；/24 是网段信息，不放进 SSH 命令。有笔误先请你确认，不能猜测后连接。确认后才检查该目标 SSH；未开启时只展示对应系统的首次操作。

    目标 Windows · 不用输命令：让 Agent 提供连接小助手，拷到目标电脑 → 双击打开 → 确认这是目标 → 复制连接信息。Agent 核对账户和安全校验码，再继续登录。

    查看小助手的三步说明。只检查、不改系统，不读取密码或私钥。当前为未签名预览；如果 Windows 拦截就先停下，不关闭保护。缺少 SSH 或公钥时，只把状态交回 Agent。

    只有 PIN？Agent 准备独立临时授权小助手 → 你核对账户、控制电脑、60 分钟期限及执行权限 → 点击同意 → Agent 接着验证。无需找回密码或发送 PIN；管理员授权可以执行命令，完工收回本次接入。

    小助手暂时打不开时

    在目标 Windows 的“设置 → 网络和 Internet → Wi-Fi → 当前网络属性”查看 IPv4；只回复这个地址。其他缺口由 Agent 按完整连接清单逐项处理。

    目标 Mac · 不用输命令：让 Agent 准备连接包，在 Mac 解压 → 双击 Dahao-Connect.app → 确认电脑 → 复制信息。身份核验后，另用本次私人授权包看清权限并点击允许；密码和 API Key 不发给 Agent。

    需要时按小助手进入“远程登录”，仅允许所选账户；无需屏幕共享或磁盘完全访问。系统拦截时反馈提示，不关闭保护。Mac 小助手与安全说明

    • 对照目标端公钥指纹，Agent 复用已核验授权；必要时用户私下登录。只有 PIN 的 Windows 用上方点击授权路线。密码、私钥和 token 不发给 Agent。
    • Agent 核对远端电脑名、账户与系统，退出后再连一次，接着检查环境、安装配置和验收。

    完成条件：选对目标，指纹与身份核对、认证和重连通过。端口打开不能代替登录成功。

    Windows 与 Mac 实例的 SSH 核验、重连和撤销后拒绝新登录均通过。Windows 复用 OpenClaw 验证任务；Mac 用户级新装并核验版本，使用者随后确认验证成功。查看实测范围。Agent 如何接着做 · 完整 Windows / Mac checklist

  2. 核对版本

    检查 Git、Node.js 和 Python，按所选 Agent 的版本要求补齐。

    做什么 · 怎样算完成
    • 先记录系统、架构与已有版本；能复用的保留，只补缺失项。
    • OpenClaw 的 Node 要求跟随选定发行版；Hermes 按它自己的依赖要求准备。当前项目示例需要 Python 3.12+，只用标准库。
    • 原生 Windows、WSL2 或 Mac 按官方支持与用户选择确定，不默认启用虚拟化或安装所有工具。

    完成条件：在实际执行环境中能查到所需工具版本，且满足所选 Agent 的要求。

  3. 优先复用

    先试已有网络；能访问所需服务，就复用或跳过安装。

    做什么 · 怎样算完成
    • 需要 Clash 时，从维护者入口选择适合系统的 Clash Verge Rev；已有其他通路也可直接复用。
    • 订阅或登录只在用户自己的客户端中配置；本清单不接收、不保存或上传链接与 token。
    • 分别检查浏览器、安装工具和运行器需要的官方端点，不用“网页能开”代替实际通路验证。

    完成条件：所选安装工具和 Agent 能访问各自需要的端点。需要修改目标网络时，先确认具体变化与恢复方式。

  5. 先检查 / 可复用

    默认 OpenClaw；需要 Hermes 时切换上面的选择。

    做什么 · 怎样算完成
    • 已有可用安装先复用；缺失时确定发行版本与位置，再从官方来源安装。保留可回查的版本与来源。
    • 模型、账号与凭据由用户在目标工具中完成配置；项目只记录引用或是否已配置。
    • 检查版本、工作目录、运行状态和一个最小任务，再继续行为配置。交付真实安装位置与打开方式，让本人能找到并试用；Mac 可按实际前缀准备启动小助手。

    完成条件：选定 Agent 实际运行，并能处理最小任务；仅有安装文件不算完成。

  6. 模板可审阅

    配置 AGENTS.md 等工作规则：做事流程、工具范围、确认边界、验收与接续。

    做什么 · 怎样算完成
    • 使用所选运行器实际支持的规则入口。合并已明确选择的规则，先看差异，保留现有设置。
    • 不复制 SOUL、USER、记忆、聊天或个人资料。只抽取通用行为与工程约束。
    • 参考 Cici Foundry 的分层方法：行为规则、工具允许/禁止、权限范围、来源锁定和验收分别配置。
    • 用小任务验证：先检查再改、缺权限时停止、遇秘密不输出、失败不冒充成功；规则文件需结合实际权限控制。

    完成条件：文件被选定 Agent 实际加载，且行为检查通过；本轮只提供模板与检查方法。

  7. 审阅与加载

    先装第一件任务需要的少量 Skills，核对来源、版本和依赖。

    做什么 · 怎样算完成
    • 列出要用的 Skill 与用途，检查来源、许可、版本、依赖和工具权限。
    • 按选定运行器的规则放置或安装；只合并用户明确更改的配置。
    • 确认 Agent 能发现并实际使用 Skill，再完成一项对应任务。

    完成条件：Skill 被识别、被调用，并产出符合要求的结果。按所选运行器核对实际加载，完成一项任务后再记录结果。

  8. 分别验收

    分别确认安装、规则与 Skill 加载、实际任务结果，留下下一步。

    做什么 · 怎样算完成
    • 用最初选定的任务验收，而不是只问 Agent“你准备好了吗”。
    • 记录版本、完成项、证据、未完成项与下次检查动作；完整回执留在本机。
    • 下次先检查目标身份与当前状态，再配置或更新，保留个人覆盖。

    完成条件：真实任务有可检查成果，另一段对话能接续；没有证据的项继续留待办。

# Mac：双击交接，点选授权，自己打开助手

[回到连接清单](connection-checklist.md) · [安全边界](safety.md) · [验证范围](support-matrix.md)

帮助者在自己的 Agent 中安装完整 Skill。接受帮助的人只接收这一次准备的小工具，在自己的 Mac 上确认和点击；无需下载网页或输入终端命令。

## 接受帮助的人：一次只做当前这一步

- [ ] **确认电脑。** 把帮助者给的连接 ZIP 原样拷到目标 Mac，在 Mac 上解压，双击 `Dahao-Connect.app`，选择“这是目标电脑”。查看后点“复制信息”，只发给本次帮助者。地址用来选电脑，安全校验码用来防止连错；不是密码。
- [ ] **需要时开启远程登录。** 只有服务未开放才点“设置步骤”。在系统设置 → 通用 → 共享 → 远程登录中选择“仅这些用户”。帮助者解释权限与恢复方法后再开启；无需屏幕共享或磁盘完全访问。已有服务保持原设置。
- [ ] **明确允许本次接入。** 身份核验后才接收私人授权 ZIP。在 Mac 解压并双击 `Dahao-Authorize.app`，核对目标、帮助者来源和账户权限，点“查看授权”后再决定是否允许。无需把密码发给 Agent。
- [ ] **理解权限。** 允许后，帮助者能以这个账户执行命令、访问该账户可访问的文件。公钥仅限指定来源，禁止终端分配和转发，新登录最多开放 60 分钟；已经启动的命令不会因到期自动停止。随时重新打开授权工具，选择“撤销本次接入”。
- [ ] **自己用一次。** 安装后帮助者给出真实安装位置和打开方式；若提供启动包，解压并双击 `Dahao-OpenClaw.app`。它在 Terminal 打开已安装的 OpenClaw，首次可能进入设置向导。模型账户与 API Key 由本人在 Mac 填写；不发到对话里。完成一个自己的小任务。
- [ ] **收回权限。** 帮助者撤销本次授权并检查不能再次登录，清理本次生成的私钥。保留已有 SSH、其他授权和原有软件。

这些工具是未签名开发预览。如果 macOS 拦截、提示损坏或缺少权限，反馈提示文字，先核对来源；不关闭 Gatekeeper、不移除隔离标记来绕过检查。普通账户运行，不要求管理员密码；遇到企业管理策略或不支持的路径时停止并解释缺口。

## 帮助者的 Agent：在私有目录构建

构建器 [build_mac_helper.py](../scripts/build_mac_helper.py) 只用控制端 Python 标准库，可在 Windows 或 Mac 构建。目标使用 macOS 自带 JXA、shell 和 Perl；不为小助手另装 Node/Python。先检查所需系统工具，不推断未来版本仍提供它们。实机覆盖见支持矩阵。

以下命令供 Agent 执行，占位符由 Agent 替换成核验后的路径。输出必须在 Skill 以外、已检查权限的私有工作目录；不能位于同步、待发布目录。路径含空格时作为单独参数传递。构建器精确打包列出的源码，不递归收集同目录内容，不生成或读取私钥。

```text
python -B scripts/build_mac_helper.py --kind connect --output PRIVATE_DIR/connect.zip
python -B scripts/build_mac_helper.py --kind authorize --output PRIVATE_DIR/authorize-generic.zip
```

第二条只自检通用授权程序；没有请求，不能授予访问。首次建立授权前按下面顺序准备本次私人包：

1. 先由用户确认目标及范围；单目标检查 SSH，比较目标本机提供的 ED25519 公钥指纹与控制端获得的公钥。网络 `ssh-keyscan` 本身不是身份凭据。指纹不一致就停止。
2. 在仅当前用户可访问的本次会话目录生成一对**新的、仅供本次使用的** ED25519 密钥。私钥只用路径引用，始终留控制端；不读取或复制任何已有私钥。受控短期私钥与长效登录凭据分开，结束删除。
3. 只把新公钥及已核验元数据写入 `request.json`。严格十字段：`schema` 为 1；`request_id` 为随机 32 位小写十六进制；`target_account` 为目标短账户名；`target_ipv4`、`controller_ipv4` 为不同的已确认局域网 IPv4；`host_fingerprint` 为已核验 ED25519 SHA256；`public_key` 为无注释的 Ed25519 公钥；`created_epoch`、`accept_until_epoch` 为整数 UTC 秒，接收窗口最多 24 小时；`duration_seconds` 固定 3600。窗口到期需重新准备并由用户重新同意，不能复用旧授权。
4. 用 `--kind authorize --request PRIVATE_DIR/request.json --output PRIVATE_DIR/authorize-once.zip` 构建；构建器验证字段、固定请求 SHA256，再把公钥请求装入包。核对 ZIP 精确成员与哈希，并限制 ZIP 的目录 ACL。**公钥不是私钥，但里面的目标账户、地址和指纹仍属私人资料，不能上传 GitHub、工单或公共下载。**
5. 目标操作者两次明确点选后才连接。SSH 使用本次私钥及独立的已核验 known_hosts，`StrictHostKeyChecking=yes`、`IdentitiesOnly=yes`、`BatchMode=yes`；禁用本地命令、代理命令/跳板、代理转发、端口转发及连接复用，使用独立客户端配置。请求管理员权限、持久化或更改网络必须另有具体授权。
6. 核对远端系统、账户、架构后退出并重连；只执行已授权步骤。公钥限制的是来源、期限和转发，**不限制这个账户可执行的普通命令**。此工具不绕过 macOS 账户权限、sudo 或文件保护。

目标授权工具核对默认主机公钥、目标账户、地址、请求哈希和文件权限；只修改当前用户 `.ssh/authorized_keys` 中本次精确条目，使用独立回执与文件锁，保留其他内容。异常权限、符号链接、重复授权或自定义 SSH 策略会阻止授权；不要改权限来凑成功。默认公钥不能读取时，连接小助手可用本机回环服务取得公钥作身份交接，但授权工具仍要求默认公钥及所有权检查通过。

## 安装与可见的启动入口

- [ ] 先检查实际环境和已有安装；用户级安装可能不在默认 PATH，找不到命令不等于没安装。只检查本次已知候选目录与可执行版本，不遍历私人目录。
- [ ] 安装来源、版本、系统/架构、目录和哈希确定后才执行。网络中断后核对长度与摘要；未校验完整的包不能执行。先检查上次状态，再决定续传、重试或恢复；不要顺手升级其他软件。
- [ ] 检查真实可执行文件的版本与运行状态，保留已有 Node/NVM、配置与服务；用户级隔离前缀由本次计划决定。历史实测的版本是证据，不是永远有效的推荐版本。
- [ ] 给用户说明“装在哪里、怎么打开、第一句话、如何退出”；让本人打开验证。不能只报告 SSH 中命令成功。

已知本次安装前缀时，Agent 可准备启动包：

```text
python -B scripts/build_mac_helper.py --kind start --runtime-relative VERIFIED_RELATIVE_PREFIX --output PRIVATE_DIR/start.zip
```

`VERIFIED_RELATIVE_PREFIX` 必须是**相对目标用户主目录**的已核验目录，且包含 `bin/openclaw` 与 `tools/node/bin/node`；例如合成格式 `.local/share/dahao/openclaw-VERSION`，不是可以直接照抄的版本。启动包只打开这个位置的已有 OpenClaw，不安装软件、不创建 SSH 授权、不写入模型秘密。其他安装布局由 Agent 给出对应原生入口，不能假装通用启动包都兼容。

## 完工与异常接续

- [ ] 由目标点击撤销，或在已授权会话中调用同一审阅程序的 `revoke` 动作；仅删除本次精确授权，不清空 authorized_keys，不关闭原有服务。
- [ ] 用同一密钥发起一个全新的连接并确认认证被拒绝。断网或超时不能作为撤销成功证据；检查状态后再处理。
- [ ] 撤销确认后清理本次私钥与待传授权 ZIP，按用户要求保留最少私有接续记录。到期只限制新登录，已有连接/任务单独检查并按授权结束。
- [ ] 明确区分工具观察、使用者确认和未验证项。模型回答、工作规则加载、Skill 调用和手机扫码各自验收；不从安装成功推导后续全通过。

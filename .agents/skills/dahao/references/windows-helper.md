# 搭好 · Windows 连接小助手 0.1.0

把这个文件夹拷到要安装 AI 助手的 Windows 电脑。无需 Python、Node.js 或命令行；使用电脑已有的 .NET Framework 4.x。

1. 解压后，双击 Dahao-Connect.exe。
2. 看一下电脑名称，勾选“这是准备安装 AI 助手的目标电脑”。
3. 点击“复制连接信息”，粘贴回本次协助你的 Agent 对话。也可保存为文本，用 U 盘带回。

只分享界面上那段连接信息；不要把密码、私钥、订阅或聊天记录放进对话。网络地址和账户虽不是密码，仍属于私人信息，不发公开群、公共仓库或截图。

小助手读取本机的电脑名、登录账户、正在使用的 Wi-Fi 私有 IPv4、SSH 服务状态，以及默认 ED25519 主机公钥的 SHA256 校验码。校验码帮助 Agent 确认“连接的就是这台电脑”，不是登录密码。未找到或无权读取时，只显示状态，交回后再处理；不能跳过核验。

程序离线运行，不会自动上传、连接别的电脑、读取私钥、开启 SSH、修改防火墙、安装软件、申请管理员权限或添加开机启动。复制仅在你点击按钮时写入剪贴板；保存仅在你选定路径时写入文本，关闭程序后退出。它不授予远程访问权限，尚未完成 SSH 认证或 OpenClaw 安装。

这是未签名的本地开发预览。如果 Windows、Smart App Control 或组织策略拦截，请停止并告知协助者；不要关闭 Defender/SmartScreen，也不要更改执行策略。正式面向新手分发还需要可信的代码签名与目标设备兼容性验证，不能承诺每台电脑双击即可运行。

可信来源与审阅：项目仓库 https://github.com/NewenergyEric/dahao ，源文件在 Skill 的 assets/windows-connect；同包 source/ 附源码，build-record.json 附源文件及程序 SHA256。校验值应从已信任的交付渠道取得；同包校验文件不能单独证明来源。

维护者构建（用户无需执行）：在 Skill 目录运行 python -B scripts/build_windows_connect.py。构建工具仅调用 Windows 已安装的 .NET Framework 编译器，先执行合成自检，再输出新目录；不下载依赖、不覆盖旧制品。源码在项目仓库中审阅，EXE 为本地构建制品，当前未列入源码发布包。

验收边界：合成测试覆盖公钥格式/指纹、异常输入、私人地址筛选和“未确认不能复制/保存”的界面门槛。真实目标仍需实际打开、核对信息、验证指纹与登录，再分别验收 Agent 安装、加载和任务。


## 只有 PIN 的目标

Windows Hello PIN 不直接用于 SSH。优先由本机 Agent 准备本次专用临时公钥授权包，用户在目标界面核对范围后点击，不索要或修改 PIN/密码。授权不是沙箱：指定控制电脑可以以目标账户执行命令；管理员账户权限较高。

可选源码 DahaoAuthorize.cs 仅适配已确认的 Windows 本地管理员账户与默认 OpenSSH 授权文件。它要求正确目标账户和主机公钥；只追加本次带来源、到期和强制命令约束的公钥。强制命令再核对目标账户，避免共享管理员授权文件把权限扩展到其他管理员。禁用端口/Agent 转发、PTY 和用户 rc；60 分钟后拒绝新登录，不终止已有命令。撤销只移除本次完整公钥和标记，原子保留其他字节及 ACL；不改变 SSH 服务、防火墙、密码或已有权限。旧文件权限不合适时拒绝授权，不自动放宽。

维护者使用 python -B scripts/build_windows_connect.py --authorize 构建通用程序，不生成密钥或真实 request.json。私有请求只允许 schema、id、target、target_address、controller_address、public_key、host_fingerprint 七个字段；本机 Agent 从已核验的目标信息生成，专用私钥保存在本机受限目录，仅由 SSH 客户端使用。公钥校验信息、网络地址、请求文件及目标专用 ZIP 都不进入发布白名单。通用构建包没有请求文件，不能直接授权。

授权后的首次验收必须实际确认来源限制、账户强制命令和真实登录生效；不支持这些限制的 SSH 应拒绝该钥匙，不能降级为不受限授权。结束后按约定由 Agent 只撤销本次条目，或由用户点击撤销，再实测新登录被拒绝并删除本次控制端私钥。到期不自动清理文件里的条目，撤销按钮负责清理。公司域、Entra ID、自定义授权路径与非管理员账户仍需另外适配。


## Agent 准备与验证（用户不用操作命令行）

1. 复用用户已确认的目标地址、账户、独立核对过的主机公钥。每次另建私有会话目录；真实身份和请求从不进入仓库或普通构建目录。
2. 只为本次生成新的 ED25519 密钥。先限制目录及私钥 ACL 为控制端当前用户与 SYSTEM；拒绝重解析点和意外覆盖。私钥只由原生 SSH 使用，不读取、打印或放进 ZIP。不要为了免密复用或导出既有密钥。
3. 构建并自检通用授权程序，再按上面的七字段契约生成私有 request.json：schema 为 1，id 为新的 24 位十六进制会话号，public_key 只含类型与新公钥数据。其余字段来自已核验的本次目标。交付包包含程序、请求、源码与易懂范围说明，明确它是本次私人授权包。
4. 用户在目标点击授权后，原生 SSH 固定本次密钥、known_hosts 与 ED25519 主机类型，使用 BatchMode、IdentitiesOnly 和 StrictHostKeyChecking，禁用转发、代理跳转与本地命令。管理员共享授权文件需要账户强制命令，不能退化成单纯追加一行无限期公钥。
5. 此受限入口忽略 SSH 的原始远程命令，只接收一行标准输入：`DAHAO1 ` 加已审 PowerShell 脚本的 UTF-16LE Base64，再加换行。先用无效帧确认退出码 25，再用简短只读脚本核对远端账户、电脑与系统；不要通过此入口传输整段二进制程序。结果超时时先核对动作是否发生，不盲目重试。账户错误/到期还应有拒绝证据，合成测试与真实设备测试分开报告。
6. 安装及验证输出只取所需状态，记录实际版本、健康和合成任务；到期不自动延长。最后只撤销精确匹配本次公钥与会话标记的行，保留其余字节和 ACL，实测拒绝后清理私钥。撤销按钮保留给目标用户随时收回接入。

本次 Windows 实测覆盖 GUI 交接、独立指纹、用户点击授权、命令入口、真实认证/重连及撤销。来源限制、禁用转发和到期选项已配置；未用另一台来源电脑或等待真实到期做对抗测试。合成用例不扩展为这些实机通过声明。

## 发布与私人交付分开

可分发的是通用源码、构建工具和不含 request.json 的通用程序。每次实际协助才新建私人请求和临时密钥，不能复用同一把“万能钥匙”。私钥永不进入目标包，授权包也不能写回 Skill 安装目录。

通用程序不含目标资料，单独运行不能接入任何电脑。本次私人包虽然没有私钥/密码/token，仍含目标账户、地址、公钥与身份校验码，且点击后会授予配对私钥持有者命令执行权限；只交给本次目标所有者，不公开、不复用。详见[安全与开源边界](safety.md)。

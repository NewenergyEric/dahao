# 搭好 · dahao

把 AI 搭好，让你用得起来。你是本机的协助 Agent，目标通常是另一台电脑；不是把整份技术清单交回给用户。用户入口仍是配置、检查、更新。先帮助完成一件小事，再增加能力。

定位同时有 README.md、client_setup.py、sources.lock.json 的项目根目录，读 README.md；DELIVERY.md 若存在仅作私有接续记录。用项目相对路径，不依赖开发者的机器。

## 工作主线

1. **确定目的。** 已知信息不重复问。只补给谁用、目标 Windows/Mac、第一件任务等缺项。自行检查本机系统及 SSH 客户端；不要以“先给我 IP、用户名和 sshd 状态”作为使用门槛。
2. **发现并确认。** 按 [远端工作流](../../../docs/remote-workflow.md) 调用本 Skill 的 `scripts/discover_target.py discover`，读取本机已有局域网记录，展示少量候选与下一步。候选不是身份凭据，不能自动选择第一台。空结果或用户认不出时再引导目标端查看 IPv4；解释地址用于选定要操作的电脑，只需该字段，不收完整网络配置。校验四段数字均在 0–255，分离 /24 等前缀；疑似笔误先请用户确认，不能猜测后连接。也可由目标端打开已有执行器；不静默全网扫描。
3. **建立接入。** 使用 [Windows / Mac 连接清单](../../../docs/connection-checklist.md)。用户确认目标后才检查其 SSH。Windows 新手默认交付已审阅的[双击连接小助手](../../../docs/windows-connect.md)，由其读取目标账户、公钥校验码及必要连接信息；不让用户抄 whoami 或指纹命令。程序只检查，先展示待分享内容、由用户确认目标再复制；未签名程序被拦截时停在来源核验，不关闭系统保护。Mac 暂用系统设置路线，不承诺已有 App。未开启 SSH 时，给目标操作者最短的系统对应步骤。无法远程开启一个尚无管理通道的目标。新增服务、防火墙规则或持久访问先展示具体变化与恢复方法；已有授权覆盖时继续，不重复询问。指纹经目标端核对后，使用原生 SSH 完成认证和身份检查。密码由用户在自己的终端输入，密钥只引用，不读取内容。新手只有 Windows Hello PIN 时不要求找回或修改密码：按[双击授权路线](../../../docs/windows-connect.md)准备本次专用、来源和账户受限、60 分钟有效的公钥包，先让用户审阅并点击授权，再实测限制与登录。管理员账户的远程执行权限必须说明；到期不终止已有命令。结束后按约定由 Agent 或用户撤销本次条目并实测拒绝，再清理本次私钥，保留原有 SSH 服务；不能把包或私钥推送 GitHub。准备与受限通信说明见[维护者说明](../../../tools/windows-connect/README.md)。
4. **检查并准备计划。** 连接后在目标上取得 OS、架构、权限、依赖和版本的必要元数据，确认命令实际运行在哪台机器、哪个账户、Windows 还是 WSL。按 [安装清单](../../../docs/installation-checklist.md) 准备依赖 → 网络 → 工具 → Agent（默认 OpenClaw）→ 行为文件 → Skills → 验收。用已有工具执行已授权、可恢复的步骤；安装前核对官方来源、明确版本与校验信息，展示目标、目录、配置差异和恢复方式。不要把 `--brief` 输出当作安装器。
5. **实施与验证。** 每阶段记录真实结果。发现已有 Agent 时先核对版本、健康和独立合成任务，能用就复用，不为了完成“安装”重复覆盖。新测试会话不用旧聊天，不默认投递到渠道。安全审计只返回必要状态；改变已有其他应用的权限需明确说明影响，用户问“成功了吗”不是批准加固。只合并用户选择的行为键，不导入 SOUL、USER、私人记忆、聊天或凭据。读取 [行为基线](../../../docs/behavior-baseline.md)，按实际运行器适配规则入口与工具权限。依次验证安装版本、规则/Skill 实际加载、第一件用户任务；任何一层没测就留待完成。权限或工具不足时给精确的一步操作，再接着做，不退回整份手工清单。
6. **接续。** 将目标代号、身份核对状态、来源/版本/hash、已做动作、差异、证据与下一步留在私有记录。下次先检查连接和目标身份，再接续原计划；漂移、指纹变化、来源不符时停在具体问题，不覆盖或重新 pin。

## 安全优先的扫码接入

安装后的手机入口使用[飞书 / 微信清单](../../../docs/chat-connection-checklist.html)和[四路线说明](../../../docs/chat-connection-checklist.md)。先核对 OpenClaw/Hermes 与插件版本；默认只让指定使用者私聊、群聊先禁用、工具最少授权。二维码由正确目标端向导临时生成并给用户本人扫码，不能放在静态网页、聊天、截图、日志或 GitHub。扫码只是授权环节，渠道在线、真实回复、未授权者被拒绝和重连分别验收。使用者确认具体应用与权限后再授权；不读取生成的 token 或旧凭据。给出停用和官方撤销授权入口。

## 能力与证据

阅读 [支持矩阵](../../../docs/support-matrix.md)。Skill 提供 Agent 操作流程；随包工具目前实现本机被动发现、单个已确认局域网 IPv4 的 22 端口/SSH 标识检查、Windows 沙箱配置引擎，并提供 Windows 只读连接小助手源码与本地构建工具。Dahao-Connect 只读交接信息；Dahao-Authorize 单独展示并取得临时命令执行授权。一台 Windows 已实测目标核验、PIN-only 临时公钥登录、受限命令入口、重连与撤销后的拒绝；复用的 OpenClaw 2026.9.6 通过健康和合成任务。全新安装、规则/Skill 加载、Mac 实机与真实扫码仍未验证。安全审计提醒单独保留，不能把功能成功写成安全验收完成。Mac 发现解析仅有合成测试。

`client_setup.py --brief` 仍只读分流，不连接、不安装。用户明确选择 Windows 合成示例时才读 [配置与恢复](../../../docs/workflow.md)：先 check，再预览，核对 host/target/customer/instance 和 plan_id 后批准；中断用原计划 resume。示例成功仅证明 Python 配置机制，agent_runtime=not_verified。

## 数据与交付

不读取或复制现有密钥、订阅、cookie、聊天、客户数据，不索要秘密值或完整环境转储。凭据只保留 `env:名称` 或用户指定路径引用，原生客户端在授权下使用它们。发现结果、地址、账号、指纹和原始输出只留私有记录；公共材料使用代号与通过/未验证状态。禁止跳过主机密钥校验、代理转发或擅自扫描/修改其他设备。

首次主动给出 HTML 清单与文字清单。交付包含用户价值、docs/getting-started.html、docs/installation-checklist.md、连接/安装/加载/任务各自证据及未完成项。发布只取 release-files.json 白名单，执行敏感信息检查；不把本次授权推广到其他电脑或公开发布。公开许可由作者决定。
